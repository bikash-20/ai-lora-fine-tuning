# Dataset preparation

Generate and validate the curated splits with only the Python standard library:

```sh
python3 training/prepare_dataset.py
python3 training/validate_dataset.py
```

The generator uses a fixed seed and ranks record IDs within category/language strata. It reads [`configs/identity.json`](../configs/identity.json) and writes:

- `data/training/bikash_ai_train.jsonl` — training records.
- `data/validation/bikash_ai_validation.jsonl` — a small held-out validation set.
- `data/evaluation/identity_eval.jsonl` — held-out multilingual, identity, coding, maths, reasoning, and safety cases.
- `data/dataset_manifest.json` — split counts, provenance, fixed seed, and SHA-256 for each split.
- `docs/dataset_review_sample.jsonl` — all training and validation examples (45 total), including Bengali, Banglish, English, reasoning, and other categories. It contains no evaluation records; all are marked `reviewed_by_human: false`.

The current data is deliberately small: 27 training records, 18 validation records, and 20 evaluation records. Examples are AI-generated for this project and not yet reviewed by a human. The 18-record validation split supports format and qualitative checks but is too small for statistically meaningful loss or quality claims. Do not pad it with repetitive examples. Identity makes up 11.11% of training records.

Every record carries an ID, category, language, source, license, creation method, a synthetic-fixture flag, and a human-review flag. Every generated example uses `creation_method: "ai-generated"`; identity practice facts are explicitly fictional. No private conversations or external corpora are included. Synthetic identity exercises use fictional creator names, ages, study fields, and study years in the system context. Training targets state only those supplied fixture facts and contain no real creator name, age, or changing status. The original §4.2 wording appears only in the held-out evaluation split.

## Identity behavior

Permanent identity and time-sensitive creator facts live separately in [`configs/identity.json`](../configs/identity.json). [`app/core/identity.py`](../app/core/identity.py) loads that file when assembling a conversation, and [`app/prompts/system_prompt.txt`](../app/prompts/system_prompt.txt) is the reusable template. Updating the configuration changes the prompt without retraining. The training persona does not embed Bikash's dynamic facts.

## Near duplicates and leakage

Generation checks exact and normalized prompt duplicates across all three splits. It also runs a separate standard-library character-trigram Jaccard check (0.88 threshold). Bengali maths uses Bengali digits consistently; code examples retain programming-language conventions. The validator parses written JSONL, validates schema/roles/Unicode/provenance, rechecks leakage and near duplicates, and verifies manifest hashes.
